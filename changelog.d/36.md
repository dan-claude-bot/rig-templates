### Added

- `gig-server`, the first machine role with an `install.sh`: `HOST="yes"`, it
  installs gig from an operator-supplied tarball and places `/etc/gig/gig.yaml`
  after `gig config check` (#36).
- `gig-server` makes the system user `gig`, runs `box grant --service gig` with
  `gig.yaml`'s pool and caps, and installs garm, garm-cli and the Incus
  provider verified against its own `checksums` file (#36).
- `gig-server` places empty `app-key.pem` and `notify.env` slots that are never
  overwritten, an inert `garm.service` and a 2G journald cap; it never writes
  garm's `config.toml` (#36).
- CI converges `gig-server` twice in `debian:13` against a fixture gig and
  checks the tampered-asset and unrecorded-pin refusals (#36).
